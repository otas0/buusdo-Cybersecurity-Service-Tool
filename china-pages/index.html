告知书

关于中国大陆入口与 Workers 强制引导的告知书

尊敬的用户：

感谢您对 buusdo Cybersecurity Service Tool（以下简称「本项目」）的关注与支持。现就中国大陆网络环境下的入口安排，告知如下：

一、原因及范围

本项目的完整检查能力运行在 Cloudflare Workers（ https://buusdocst.mtsu.workers.dev ）。在部分中国大陆网络环境下，该域名可能出现延迟、超时或不可达，用户难以正常完成检查。

自 2026 年 11 月 22 日 起，中国大陆 GitHub Pages 入口（ https://otas0.github.io/buusdocst/ ）仅保留本告知书（产品说明 / 隐私摘要 / 安装指引已下线）。自 2026 年 11 月 23 日 起，当访客经 Cloudflare 判定来自中国大陆（ CF-IPCountry=CN ）并打开 Workers 产品站时， 将强制跳转至本告知书 ，以免在不稳定网络下误以为完整检查可用。 完整检查界面仍位于 Workers；API（ /api/* ）不跳转，扩展与机器调用不受影响。

说明：上述安排针对中国大陆网络环境； 不表示 Workers 在全球其他可访问网络中一律不可用。

二、两套入口如何配合

本项目存在两套相关站点入口：

  • 中国大陆入口（本站）— https://otas0.github.io/buusdocst/ （告知书；大陆访客从 Workers 被强制引导至此）
  • Workers 完整检查站 — https://buusdocst.mtsu.workers.dev （正式检查与产品界面，如 /zh-Hans、/zh-Hant、/en）
  1. 访问 Workers 且检测为中国大陆 ：强制跳转至本告知书（可用 ?china_workers_stay=1 临时留在 Workers，供运维自测）。
  2. 停留在本告知书 ：本页仅做只读健康探测并显示可达性； 不再自动跳回 Workers （避免与上一条形成循环）。需要完整检查时请手动打开下方链接。
  3. 当前网络无法到达 Workers ：继续阅读本告知书；本项目不对中国大陆地区访问可用性作出承诺。

三、关于网络环境检测与隐私

  • Workers 侧 ：Cloudflare 请求头 CF-IPCountry （仅用于是否强制引导至本告知书；不用于画像或广告）。
  • 本页探测 ：浏览器向 Workers 发起只读 GET /api/health （短超时、不携带 Cookie），用于显示可达性； 不触发自动跳转。
  • 不调用 ：检查接口 /api/check （完整检查仅在您进入 Workers 并提交地址后发生）。
  • 语言偏好 ：中文 / 英文选择仅保存在本机 localStorage （buusdocst-china-lang），不上传。

更完整的隐私说明以 Workers 正式隐私页为准： https://buusdocst.mtsu.workers.dev/zh-Hans/privacy （若您位于大陆网络，打开该链接时可能再次被引导回本告知书）。

四、服务恢复

中国大陆入口页的恢复时间暂无法确定。待条件具备后，本项目将另行发布通知。在此期间， 本项目不对中国大陆地区访问入口页或 Workers 的可用性作出任何承诺。

五、联系方式

如您位于可到达 Cloudflare 的网络却无法进入 Workers，或对本告知书有疑问，请通过 GitHub Issues 联系。对由此带来的不便，我们深表歉意，并感谢您的理解与支持。

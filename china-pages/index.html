中国大陆访问说明

完整检查服务运行在 Cloudflare Workers（ pcpd.mtsu.workers.dev ）。在部分大陆网络下该域名可能较慢或超时，这不一定代表服务宕机。

本页由 GitHub Pages 托管，便于在 Workers 不可达时仍能打开产品说明、隐私政策与扩展安装指引。

可用入口

  • 隐私政策（中文摘要）
  • Chrome / Safari 扩展安装
  • 完整网站检查（需可访问 Cloudflare）

产品做什么

busdo（Cybersecurity Service Tool）在信任网址前，用自有威胁列表、地址结构、品牌仿冒信号、DNS 与可达性做检查。不把网址送给第三方信誉服务。

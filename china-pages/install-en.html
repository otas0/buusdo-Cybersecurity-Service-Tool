Install

Chrome

Official path: Chrome Web Store → search buusdo Cybersecurity Service Tool → Add to Chrome. Store URLs stay empty in product config until the listing is live; until then use the developer package / sideload notes you were given.

The extension talks to https://buusdocst.mtsu.workers.dev by default. A Workers timeout on this network shows a dedicated message — that does not mean the extension is broken.

Safari

Safari (macOS)

Official path: Mac App Store → install the buusdo Cybersecurity Service Tool wrapper app → Safari → Settings → Extensions → enable. Store URL stays empty until the listing is approved.

Desktop

Desktop app (GitHub, unsigned)

Download Windows / macOS zip / Linux deb from GitHub Releases. The current mac zip is about ~58 MB. Builds are not notarized / not code-signed: macOS may block the first open (Gatekeeper); Windows may show SmartScreen (“Unknown publisher”) — expected for this ship path. Same steps as Workers Settings: Setup guide (unsigned) (same as Workers Settings → Setup guide).

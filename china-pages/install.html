Install

Chrome

正式方式：Chrome 网上应用店搜索 buusdo Cybersecurity Service Tool → Add to Chrome。商店链接上架后会写在产品配置里；未上架前请使用开发者提供的安装包说明。

扩展默认连接 https://buusdocst.mtsu.workers.dev 。若本机访问 Workers 超时，会显示专用提示，不代表扩展损坏。

Safari

Safari（macOS）

正式方式：Mac App Store 安装 buusdo Cybersecurity Service Tool 包装应用 → Safari → 设置 → 扩展 → 启用。

Website

完整检查站

网络允许时打开 Workers 上的完整检查界面。

打开完整检查 返回入口

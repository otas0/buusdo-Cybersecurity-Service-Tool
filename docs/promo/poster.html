English

Check a website

Type any website address. We check our own threat list, structure, brand lookalikes, DNS and live response. On Halt: leave, verify on an official channel you already trust, then optionally report.

Next

  1. 01Leave this page now — do not continue on the address you checked.
  2. 02Do not enter passwords, card numbers, codes from SMS/email, or other personal data on this site.
  3. 03Verify independently: open the organisation’s official domain or app you already trust (bookmark, bank card, known app store). Do not use phone numbers or emails shown on the suspect page.
  4. 04Optional: block the host in the buusdo extension or desktop app so it is harder to reopen by mistake.
  5. 05Optional: save a local report draft below so an operator can review the host for the curated threat list.

Halt

Leave this check — You may hand over passwords, payment details, or other personal data to whoever controls this address. Close the tab before typing or paying anything.

Data

Default: nothing is stored. Diagnostics only help fix technical problems — never the address, and never for public release.

buusdo does not offer a cloud account or cross-device list sync. Personal block/trust lists stay on this device. Move them with export/import of shield-lists-v1 JSON or QR, or sync the desktop shield-backup.json file yourself (USB, Drive, Syncthing).

Honest limits of this tool

buusdo cannot erase personal information a website already collected from you. Change passwords on the real official site if you entered anything, and watch bank/email alerts.

Clear means no strong warning from the checks run — not a promise that the site is safe.

Surfaces

Web · browser extension · desktop — local lists, reversible choices.

Scam pages often look polished and use HTTPS. Visual quality is not proof the site is legitimate.

Português

Verificar um site

Escreva qualquer endereço de site. Verificamos a lista própria de ameaças, estrutura, marcas parecidas, DNS e resposta em direto. Em Parar: saia, verifique num canal oficial em que já confia e, se quiser, denuncie.

A seguir

  1. 01Saia já desta página — não continue no endereço que verificou.
  2. 02Não introduza palavras-passe, números de cartão, códigos de SMS/email ou outros dados pessoais neste site.
  3. 03Verifique de forma independente: abra o domínio ou a app oficial da organização em que já confia (marcador, cartão do banco, loja de apps conhecida). Não use telefones nem emails mostrados na página suspeita.
  4. 04Opcional: bloqueie o anfitrião na extensão ou app desktop buusdo para ser mais difícil reabri-lo por engano.
  5. 05Opcional: guarde abaixo um rascunho de denúncia local para um operador rever o anfitrião na lista curada de ameaças.

Parar

Sair desta verificação — Pode entregar palavras-passe, dados de pagamento ou outra informação pessoal a quem controla este endereço. Feche o separador antes de escrever ou pagar o que quer que seja.

Dados

Predefinição: nada é guardado. O diagnóstico só ajuda a corrigir problemas técnicos — nunca o endereço, e nunca para divulgação pública.

O buusdo não oferece conta na nuvem nem sincronização de listas entre dispositivos. As listas pessoais de bloqueio/confiança ficam neste dispositivo. Transfira-as com exportar/importar JSON shield-lists-v1 ou QR, ou sincronize o ficheiro shield-backup.json da app (USB, Drive, Syncthing).

Limites honestos desta ferramenta

O buusdo não consegue apagar informação pessoal que um site já tenha recolhido. Se introduziu dados, altere palavras-passe no site oficial verdadeiro e acompanhe alertas do banco/email.

Limpo significa que não houve alerta forte nas verificações feitas — não é uma promessa de que o site é seguro.

Superfícies

Web · extensão · desktop — listas locais, escolhas reversíveis.

Páginas de fraude costumam parecer cuidadas e usar HTTPS. Qualidade visual não prova que o site seja legítimo.

检查网站

输入任意网站地址。我们会核对自有威胁列表、结构、品牌仿冒、DNS 与实时响应。若出现「停止」：离开页面，通过您已信任的官方渠道核实，然后可选择举报。

下一步

  1. 01立即离开此页面——不要继续使用您检查过的地址。
  2. 02不要在此网站输入密码、卡号、短信/邮件验证码或其他个人数据。
  3. 03独立核实：打开您已信任的该组织官方域名或应用（书签、银行卡、已知应用商店）。不要使用可疑页面上显示的电话或邮箱。
  4. 04可选：在 buusdo 扩展或桌面应用中拦截该主机，以免误重新打开。
  5. 05可选：在下方保存本地举报导稿，供运营人员审核该主机是否列入整理的威胁列表。

停止

离开此次检查 — 您可能把密码、付款信息或其他个人数据交给控制此地址的人。在输入或支付任何内容之前请关闭标签页。

数据

默认：不存储任何内容。诊断仅用于修复技术问题——从不包含地址，也不用于公开发布。

buusdo 不提供云端账户或跨设备列表同步。个人拦截/信任列表留在本设备。请通过导出/导入 shield-lists-v1 JSON 或二维码转移，或自行同步桌面端的 shield-backup.json（USB、Drive、Syncthing）。

本工具的诚实限度

buusdo 无法抹除网站已经从您处收集的个人信息。若已输入任何内容，请在真正的官方网站更改密码，并留意银行/邮件提醒。

「畅通」表示已运行的检查未发出强烈警告——并不保证该网站安全。

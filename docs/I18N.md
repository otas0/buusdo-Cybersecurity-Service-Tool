buusdo Cybersecurity Service Tool ships a multi-locale website UI. Extension / desktop packs follow later; website is first.

## Full vs partial packs

| Concept | Source | Rule |
|---------|--------|------|
| EN key set | `i18n/messages.ts` → `en` (and `_en.snapshot.json`) | Canonical |
| Full pack | `i18n/packs/{id}.json` | Trimmed keys ≥ `FULL_PACK_MIN_KEYS` from [`i18n/pack-coverage.ts`](../i18n/pack-coverage.ts) (`max(400, floor(0.9 × EN keys))`) |
| Partial pack | same | Below threshold → `showsPartialPackBanner(locale)` on Privacy / Settings |
| Core keys | `i18n/core-keys.ts` | Minimum chrome + Halt path every pack should cover early |

`getMessages(locale)` = normalize → merge pack onto EN (or pt-PT for `pt-BR`).

Southern Africa full packs today: `xh`, `af`, `zu`, `st`, `tn`, `nso`, `ss`, `ve`, `ts`, `nr`. Other thin Europe packs (e.g. `bg`) still show the English leftover banner.

### Soft live Halt fixture

Known-threat soft Playwright uses [`security/data/fixtures/halt-known-threat.json`](../security/data/fixtures/halt-known-threat.json) (`paypal.secure-login.example` on the curated list). ### A4 poster MessageBag keys (pack-only; no product CTA)

Product chrome (Workers AppShell / Settings, extension popup, desktop footer) must **not** link `/promo/poster.html`. Keys remain in packs for promo build scripts and placeholder parity only:

| Key | Role |
|-----|------|
| `downloadA4Poster` | Former CTA label (unused in UI) |
| `downloadA4PosterShort` | Former compact label (unused in UI) |
| `downloadA4PosterHint` | Former print hint (unused in UI) |

Gate: `scripts/assert-settings-a4-print-hint.mjs`, `tests/website-no-a4-poster.test.ts`. Keep `{placeholder}` tokens in sync with EN if any are added later (`tests/pack-placeholder-parity.test.ts`).

**Snapshot regen order** (after editing `i18n/messages.ts` EN/pt-PT strings):

1. Update `en` / `pt-PT` in `i18n/messages.ts`.
2. Refresh snapshots: copy EN → `i18n/packs/_en.snapshot.json`, pt-PT → `i18n/packs/_pt-PT.snapshot.json` (or the repo’s snapshot script if present).
3. Overlay new keys into every locale pack (native or temporary EN).
4. `npm run gen:pack-index`
5. `npm run sync:toast-i18n && npm run sync:desktop-i18n && npm run sync:extension-sea-i18n`
6. `npx tsx --test tests/pack-placeholder-parity.test.ts tests/pack-coverage-threshold.test.ts tests/i18n-locales.test.ts`

## Extend a pack

1. Edit or add `i18n/packs/{id}.json` (UTF-8). Keep placeholders `{ms}`, `{tag}`, `{status}`, …
2. Run `npm run gen:pack-index` (rewrites `i18n/pack-index.ts`).
3. Run `npm test -- tests/i18n-locales.test.ts tests/pack-placeholder-parity.test.ts tests/pack-coverage-threshold.test.ts`.
4. Spot-check `/{id}` and Halt copy.
5. Pushing `i18n/packs/**` (or `messages.ts` / `locales.ts` / `pack-index.ts`) to `main` triggers **Deploy Cloudflare** automatically.

To promote a locale from partial → full: translate every key in `_en.snapshot.json` into that pack (same key set as EN) until `isFullLocalePack(id)` is true.

## Sync / CI check list

Run via `npm run typecheck` (or individually):

| Script | Purpose |
|--------|---------|
| `npm run sync:toast-i18n:check` | Toast COPY in `phishing-toast-mount.js` matches packs; keeps `buildPhishingToast` |
| `npm run sync:desktop-i18n:check` | Desktop `STRINGS` ja / zh-Hans / zh-Hant overlay matches packs |
| `npm run sync:extension-sea-i18n:check` | Extension SEA overlay (mi / th / vi) matches packs |
| `npm run assert:pack-index` | `pack-index.ts` imports every pack file |
| `tests/pack-placeholder-parity.test.ts` | Pack `{placeholders}` match EN per key |
| `tests/pack-coverage-threshold.test.ts` | Prints / asserts `FULL_PACK_MIN_KEYS` |

Manual rebuilds (when editing packs):

```bash
npm run sync:toast-i18n
npm run sync:desktop-i18n
npm run sync:extension-sea-i18n
npm run gen:pack-index
```

## Aliases

`normalizeLocale` maps common tags (`zh` → `zh-Hans`, `zh-TW` → `zh-Hant`, `pt` → `pt-PT`, `jp` → `ja`, `tl` → `fil`, `no` → `nb`, plus SEA/SA region tags like `th-TH`, `xh-ZA`, `ss-ZA`/`ss-SZ`, `ve-ZA`, `ts-ZA`, `nr-ZA`/`nr-ZW`). URL path segments must be exact catalog ids.

## First visit / region recommend

- `/` uses `Accept-Language` → shipped locale (`lib/accept-language.ts`).
- `LocaleRecommendModal` suggests a language from `navigator.languages` until the user chooses or dismisses (`localStorage`).

## Extension / desktop

- Toast COPY (12 locales): `npm run sync:toast-i18n` → `phishing-toast-mount.js` + `phishing-toast-i18n.json`.
- Content TRACKER_COPY must cover the same 12 toast locales (`tests/extension-toast-locale-align.test.ts`).
- Desktop lang select: region optgroups from `locale-catalog.js`. Bags: en, pt-PT, zh-Hans, zh-Hant, ja (+ EN fallback for other selected locales).
- China Pages: Workers CTA lockup `打开完整检查（简体中文 /zh-Hans）` on index + install.
- Privacy: `partialPackBanner` when the pack is not full-size.

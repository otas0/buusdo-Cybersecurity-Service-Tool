## Full vs partial packs

| Concept | Source | Rule |
|---------|--------|------|
| EN key set | `i18n/messages.ts` → `en` (and `_en.snapshot.json`) | Canonical |
| Full pack | `i18n/packs/{id}.json` | Trimmed keys ≥ `FULL_PACK_MIN_KEYS` from [`i18n/pack-coverage.ts`](../i18n/pack-coverage.ts) (`max(400, floor(0.9 × EN keys))`) |
| Partial pack | same | Below threshold → `showsPartialPackBanner(locale)` on Privacy / Settings |
| Core keys | `i18n/core-keys.ts` | Minimum chrome + Halt path every pack should cover early |

`getMessages(locale)` = normalize → merge pack onto EN (or pt-PT for `pt-BR`).

Southern Africa full packs today: `xh`, `af`, `zu`, `st`, `tn`, `nso`, `ss`, `ve`, `ts`, `nr`. **All Europe catalog packs are full** (`de`/`fr`/`es`/`it`/`nl`/`pl`/`sv`/`da`/`fi`/`nb` plus CE/SE/Baltic/`ca`/`ga`/`mt`/`uk`/`is`/`sl`). Partial banner should stay off for every id in [`must-stay-full-locales.json`](../must-stay-full-locales.json).

Full-pack regression list (single source): [`i18n/must-stay-full-locales.json`](../i18n/must-stay-full-locales.json) — imported by `i18n/pack-coverage.ts` and `scripts/print-pack-coverage-summary.mjs`.

## Extend a pack

1. Edit or add `i18n/packs/{id}.json` (UTF-8). Keep placeholders `{ms}`, `{tag}`, `{status}`, …
2. Run `npm run gen:pack-index` (rewrites `i18n/pack-index.ts`).
3. Run `npm test -- tests/i18n-locales.test.ts tests/pack-placeholder-parity.test.ts tests/pack-coverage-threshold.test.ts`.
4. Spot-check `/{id}` and Halt copy.
5. Pushing `i18n/packs/**` (or `messages.ts` / `locales.ts` / `pack-index.ts`) to `main` triggers **Deploy Cloudflare** automatically.

To promote a locale from partial → full: translate every key in `_en.snapshot.json` into that pack (same key set as EN) until `isFullLocalePack(id)` is true.

## Language panel UX

Header language control (`components/LanguageSwitcher.tsx`):

- Closed state: short badge (`EN` / `简` / …) — not a long native `<select>`.
- Open panel: search + **region accordion only** (current region expanded; others collapsed until expanded or searched). **No Frequent strip** — `FREQUENT_LOCALE_IDS` is recommend-modal pins only (CI: `tests/language-switcher-no-frequent-guard.test.ts`).
- Region headings use MessageBag `langRegion*` (fallback `LOCALE_REGION_LABELS.en`).
- Search filters by native name, English name, or id. Placeholder: `langPanelSearchPlaceholder`. Empty filter: `langPanelNoMatches`.
- A visually hidden `<select data-testid="locale-select">` remains for Playwright `selectOption` and a11y fallback.

First-visit recommend (`components/LocaleRecommendModal.tsx`):

- Accept / dismiss for the suggested language.
- Empty search: pinned options from shared `recommendPinnedLocaleIds` — suggested first, then `FREQUENT_LOCALE_IDS` (`en`, `zh-Hans`, `ja`, `pt-PT`, `de`), deduped and capped at `LOCALE_RECOMMEND_PIN_MAX` (**6**).
- Hint `localeRecommendSearchHint` states pins are suggestions; **search unlocks the full catalog**. Pin buttons / list use `aria-describedby` → that hint when search is empty.
- Search / empty copy reuse `langPanelSearchPlaceholder` / `langPanelNoMatches`. Arrow Up/Down moves focus among option buttons.
- Hidden `<select data-testid="locale-recommend-select">` kept for older helpers.

## Frozen capabilities (at V0.1)

URL/domain parsing, controlled registrable-domain logic, HTTPS and punycode detection, provider abstraction, deterministic reputation fixtures, claimed-identity comparison, similarity signals, sensitive-context warnings, explainable risk states, reversible local block/trust actions, action verification, bilingual UI, methodology material.

## Known limitations

The public-suffix implementation is deliberately limited. No result proves a website safe. Similarity can produce false positives or false negatives. Blocking works only inside the product surfaces that honour local lists. No real-world effectiveness claim is made.

The controlled evaluation recorded one low-severity design limitation: block and trust are independent lists, so the same domain can appear in both. No production behavior was changed during evaluation.

## Deferred (at freeze)

Live external threat intelligence beyond the first-party curated list, a verified-organisation registry, broader browser interception, privacy/tracker protection, breach monitoring, account remediation, call/SMS monitoring, AI verdicts.
